# 🎧 Headphones Landing Page

A fully responsive landing page built from the provided Figma design. This project translates the UI mockup into semantic HTML and modern CSS, focusing on accurate layout, responsiveness, and consistent styling.

---

## 📌 Project Overview

This project is part of the **ALX Front-End Program**.  
The goal is to recreate the Headphones landing page exactly as shown in the Figma file.

The page includes:
- Navigation bar  
- Hero section  
- Features section  
- Contact form  
- Footer  

The design supports both **desktop** and **mobile** layouts.

---

## 🖼️ Figma Design

To access the design:

1. Create a **Figma account**.
2. Open the project link (as provided in the task).
3. Click **“Duplicate to Drafts”** to unlock the design details.

If unavailable, use the downloadable Figma file included in your project instructions.

## 🎨 Design Requirements

### Responsive Behavior
- When screen width is **480px or less**, the layout switches to the mobile version.
- Maximum page content width: **1000px**, centered.

### Hover & Active States
- **Links:**  
  Hover/Active → `#FF6565`
- **Buttons:**  
  Hover/Active → `opacity: 0.9`

### Notes from Figma
- Some measurements may contain decimals — rounding is acceptable.
- Ensure spacing, fonts, and alignment match the mockup closely.
